# Balatro Joker Tier List

Balatro 조커 150장을 S·A·B·C·D·F 티어로 정리하는 비공식 팬 제작 웹 앱입니다.

## 바로 실행
### 웹에서 사용

https://sanzuriverr.github.io/-/ 에 접속해서 바로 사용 가능합니다.

### 다운로드해서 사용

1. GitHub 저장소에서 **Code → Download ZIP**을 선택합니다.
2. ZIP 파일을 **전부 압축 해제**합니다.
3. 압축을 푼 폴더의 **`index.html`**을 브라우저로 엽니다.

## 저장과 백업

티어 배치와 코멘트는 사용 중인 브라우저의 `localStorage`에 저장됩니다.
서버나 GitHub에 자동으로 업로드되지 않으며 다른 사용자와 공유되지 않습니다.

- 중요한 작업은 상단 **내보내기** 버튼으로 JSON 파일을 보관하세요.
- **가져오기** 버튼으로 내보낸 JSON을 복원할 수 있습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 다른 브라우저 사용 시 저장 내용이 유지되지 않을 수 있습니다.
- 로컬 파일, `localhost`, `127.0.0.1`, GitHub Pages 주소의 저장 공간은 서로 다를 수 있습니다. 이동할 때는 내보내기·가져오기를 사용하세요.
- 로컬 파일의 자동 저장은 브라우저 정책에 따라 제한될 수 있습니다. JSON 백업을 권장합니다.
